# 第 3 層 — 執行期驗證

> 無法自動化。只能人工在 play mode 中確認「看起來對不對」「手感好不好」。

---

## 為什麼不能自動化

第 3 層驗證的是：

- **視覺**：選取框貼不貼合、材質方向對不對、霧的過渡自不自然
- **手感**：相機切換順不順、拖曳放置跟不跟手、音效時機對不對
- **完整流程**：從開場到結束，玩家能不能走完

這些沒有客觀斷言。截圖可以留證，但「好不好」要人判斷。

---

## 執行方式

1. 在 TSB Studio 開啟專案
2. `query_editor(getState)` 確認 `editorReady: true`
3. `action_editor(enterPlayMode)`
4. 逐項操作，每項通過後打勾
5. 失敗項目開 `ISSUE-XXX`
6. `action_editor(exitPlayMode)`

## 失敗分類

| 嚴重度 | 定義 | 動作 |
|---|---|---|
| `blocker` | 功能完全不能用 | 立刻修，不繼續下一組 |
| `content` | 功能可用但內容錯 | 開 issue，用 placeholder 繼續 |
| `polish` | 可用但不好看／不順 | 開 issue，Demo 後處理 |

---

## 截圖規範

每組至少一張，命名 `<組別>-<編號>-<描述>.jpg`：

```
A1-selection-box.jpg
B1-place-on-top.jpg
F1-god-view.jpg
H5-world-border.jpg
```

用 `action_editor(captureScreenshot)` 產生。
