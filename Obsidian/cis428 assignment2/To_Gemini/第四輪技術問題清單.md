## 問題 16：`tMin` 初始化為 `0` 會漏掉「貼著方塊表面」的命中

**你的寫法**：

```ts
function rayAabb(origin, dir, box, boxOffset, maxT): { t: number; axis: number } | null {
  let tMin = 0;
  let tMax = maxT;
  let hitAxis = -1;

  for (let axis = 0; axis < 3; axis++) {
    const d = dir[axis];
    const o = origin[axis];
    const lo = box[boxOffset + axis];
    const hi = box[boxOffset + axis + 3];

    if (Math.abs(d) < 1e-8) {
      if (o < lo || o > hi) return null;
      continue;
    }

    const invD = 1 / d;
    let t1 = (lo - o) * invD;
    let t2 = (hi - o) * invD;
    if (t1 > t2) { const tmp = t1; t1 = t2; t2 = tmp; }

    if (t1 > tMin) { tMin = t1; hitAxis = axis; }
    if (t2 < tMax) tMax = t2;
    if (tMin > tMax) return null;
  }

  if (hitAxis < 0) return null;
  return { t: tMin, axis: hitAxis };
}
```

**問題**：

起點剛好在方塊表面上時（例如 `origin.x = 0`，方塊 `[0, 1]`）：

- `t1 = (0 - 0) / 1 = 0`
- `t1 > tMin` → `0 > 0` → **false**
- `hitAxis` 不會被設為 0
- 結果 `hitAxis = -1` → 回傳 `null`

**這會漏掉「貼著方塊表面」的命中。**

**具體情境**：

- 玩家站在地面上，腳底 `y = 11.0`（剛好貼著地面方塊 `[10, 11]` 的頂面）
- 相機在 `y = 11.9`
- 射線朝下（`dir.y = -1`）
- 命中地面方塊的頂面 `y = 11.0`
- 但 `t1 = (11 - 11.9) / -1 = 0.9`，`t1 > 0` → 正常命中

**等等，這個情境沒問題。** 因為相機在 `y = 11.9`，不在方塊表面上。

**真正會出問題的情境**：

- 玩家站在地面上，腳底 `y = 11.0`
- 相機在 `y = 11.0`（極端情況，例如趴下）
- 射線水平朝前（`dir.y = 0`）
- 命中前方方塊的側面 `x = 1.0`
- `t1 = (1 - 0) / 1 = 1`，`t1 > 0` → 正常命中

**還是不會出問題。**

**真正會出問題的情境（第三次嘗試）**：

- 方塊 `[0, 0, 0]` 到 `[1, 1, 1]`
- 射線起點 `(0, 0.5, 0.5)` —— **剛好在方塊西面上**
- 射線朝 `+X`（`dir = (1, 0, 0)`）
- `t1 = (0 - 0) / 1 = 0`
- `t1 > tMin` → `0 > 0` → **false**
- `hitAxis` 保持 `-1`
- 回傳 `null`

**但這種情況應該命中嗎？**

- 起點在方塊表面上，射線朝內 → **應該命中**（距離 0）
- 起點在方塊表面上，射線朝外 → **不應該命中**

**你的 `hitAxis < 0` 判斷無法區分這兩種情況。**

**我的理解**：應該用 `tMin = -Infinity` 初始化，最後檢查 `tMin >= 0`：

```ts
let tMin = -Infinity;
let tMax = maxT;
let hitAxis = -1;

for (let axis = 0; axis < 3; axis++) {
  // ...
  if (t1 > tMin) { tMin = t1; hitAxis = axis; }
  if (t2 < tMax) tMax = t2;
  if (tMin > tMax) return null;
}

if (tMin < 0) return null;   // 起點在 box 內（或朝外）
return { t: tMin, axis: hitAxis };
```

這樣：

- 起點在 box 外 → `tMin > 0`，正常命中
- 起點在 box 表面，朝內 → `tMin = 0`，命中（`0 >= 0`）
- 起點在 box 表面，朝外 → `tMin < 0`，跳過
- 起點在 box 內 → `tMin < 0`，跳過

**請確認**：這個修正是否正確？還是說「貼著表面」的情況在實務上不會發生（因為相機永遠在方塊外）？

## 問題 17：`Math.sign(0)` 回傳 `0`，法向量會變成零向量

**你的寫法**：

```ts
function getHitNormal(dir, hitAxis): Vector3 {
  const normal = new Vector3(0, 0, 0);
  if (hitAxis === 0) normal.x = -Math.sign(dir[0]);
  else if (hitAxis === 1) normal.y = -Math.sign(dir[1]);
  else if (hitAxis === 2) normal.z = -Math.sign(dir[2]);
  return normal;
}
```

**問題**：

如果 `dir[hitAxis] === 0`（射線平行於該軸），`Math.sign(0) = 0`，法向量會變成零向量 `(0, 0, 0)`。

**但這種情況不應該發生** —— 因為 `hitAxis` 只在 `Math.abs(d) >= 1e-8` 時才被設定。

**請確認**：這個推論是否正確？還是需要額外的防禦？

## 問題 20：`VoxelShape` 的 `boxCount` getter 每次呼叫都做除法

**你的寫法**：

```ts
export class VoxelShape {
    constructor(public readonly boxes: Float32Array) {
        if (boxes.length % 6 !== 0) {
            throw new Error(`VoxelShape: boxes.length (${boxes.length}) must be a multiple of 6.`);
        }
    }
    get boxCount(): number {
        return this.boxes.length / 6;
    }
}
```

**問題**：

`boxes.length / 6` 每次呼叫都做一次除法。在 hot loop 裡（每個方塊、每幀）會累積。

**我的理解**：應該在 constructor 預先算好：

```ts
export class VoxelShape {
    readonly boxCount: number;

    constructor(public readonly boxes: Float32Array) {
        if (boxes.length % 6 !== 0) {
            throw new Error(`VoxelShape: boxes.length (${boxes.length}) must be a multiple of 6.`);
        }
        this.boxCount = boxes.length / 6;
    }
}
```

**請確認**：這個優化是否值得？還是 V8 會自動優化除法？

## 補充：DDA 主迴圈的實作細節

你只給了 `rayAabb()`，沒給 DDA 主迴圈。我的理解是 Amanatides & Woo：

```ts
function ddaRaycast(
  volume: VoxelVolume,
  origin: readonly [number, number, number],
  dir: readonly [number, number, number],
  maxT: number,
): VoxelRaycastHit | null {
  // 1. 起點格子
  let x = Math.floor(origin[0]);
  let y = Math.floor(origin[1]);
  let z = Math.floor(origin[2]);

  // 2. 步進方向
  const stepX = Math.sign(dir[0]);
  const stepY = Math.sign(dir[1]);
  const stepZ = Math.sign(dir[2]);

  // 3. 到下一個格線的 t 距離
  const tDeltaX = stepX !== 0 ? Math.abs(1 / dir[0]) : Infinity;
  const tDeltaY = stepY !== 0 ? Math.abs(1 / dir[1]) : Infinity;
  const tDeltaZ = stepZ !== 0 ? Math.abs(1 / dir[2]) : Infinity;

  // 4. 到第一個格線的 t 距離
  let tMaxX = stepX > 0
    ? (x + 1 - origin[0]) / dir[0]
    : stepX < 0
      ? (x - origin[0]) / dir[0]
      : Infinity;
  let tMaxY = stepY > 0
    ? (y + 1 - origin[1]) / dir[1]
    : stepY < 0
      ? (y - origin[1]) / dir[1]
      : Infinity;
  let tMaxZ = stepZ > 0
    ? (z + 1 - origin[2]) / dir[2]
    : stepZ < 0
      ? (z - origin[2]) / dir[2]
      : Infinity;

  // 5. 主迴圈
  let t = 0;
  while (t <= maxT) {
    // 檢查當前格子
    const stateId = volume.getBlock(x, y, z);
    if (stateId !== 0) {
      const shape = getBlockShape(stateId);
      const hit = testRayAgainstShape(origin, dir, shape, x, y, z, maxT);
      if (hit) return { cell: { x, y, z }, ...hit };
    }

    // 步進到下一格
    if (tMaxX < tMaxY && tMaxX < tMaxZ) {
      x += stepX;
      t = tMaxX;
      tMaxX += tDeltaX;
    } else if (tMaxY < tMaxZ) {
      y += stepY;
      t = tMaxY;
      tMaxY += tDeltaY;
    } else {
      z += stepZ;
      t = tMaxZ;
      tMaxZ += tDeltaZ;
    }
  }

  return null;
}
```

**請確認**：

1. 這個 DDA 主迴圈是否正確？
2. `tMaxX` 的計算（`(x + 1 - origin[0]) / dir[0]`）是否正確？
3. 迴圈條件 `t <= maxT` 是否應該改成 `t < maxT`？
4. 是否需要處理「起點格子」的邊界情況（例如 `origin` 剛好在格線上）？
