## 打字機效果

```typescript
class TypewriterEffect {
  private timer: number | null = null;

  play(text: string, speed: number, onDone: () => void): void {
    let i = 0;
    const interval = 1000 / speed;
    this.timer = window.setInterval(() => {
      i++;
      this.element.textContent = text.slice(0, i);   // 用 textContent，不用 innerHTML
      if (i >= text.length) {
        this.stop();
        onDone();
      }
    }, interval);
  }

  skip(text: string): void {
    this.stop();
    this.element.textContent = text;
  }

  private stop(): void {
    if (this.timer !== null) {
      clearInterval(this.timer);
      this.timer = null;
    }
  }
}
```

## UI 規範

| 規則 | 說明 |
|---|---|
| 容器 | 必須加到 `world.gameContainer`，**不可**加到 `document.body` |
| 文字設定 | 用 `textContent`，**禁用** `innerHTML` |
| 樣式 | 用 `setStyle()` 或 CSS class |
| 層級 | `z-index` 低於過場黑幕（1000），高於遊戲畫面 |

## 風險

| 風險 | 緩解 |
|---|---|
| 打字機與玩家輸入衝突 | 打字中按鍵 = 跳過當前句 |
| 對話框遮住遊戲畫面 | 半透明背景 + 可折疊 |
| 中文字寬度不一 | 用 `textContent` 逐字，不用等寬字型 |
