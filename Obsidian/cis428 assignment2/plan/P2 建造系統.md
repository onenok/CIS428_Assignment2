## 1. VoxelChunkNode（渲染核心）

| 節點 | 問題 |

### 佔位生成

```typescript
export function makePlaceholderTexture(baseColor: string, size = 32): THREE.CanvasTexture {
  const canvas = document.createElement('canvas');
  canvas.width = canvas.height = size;
  const ctx = canvas.getContext('2d')!;
  ctx.fillStyle = baseColor;
  ctx.fillRect(0, 0, size, size);
  // 加雜訊
  const img = ctx.getImageData(0, 0, size, size);
  for (let i = 0; i < img.data.length; i += 4) {
    const n = (Math.random() - 0.5) * 30;
    img.data[i] = Math.max(0, Math.min(255, img.data[i] + n));
    img.data[i + 1] = Math.max(0, Math.min(255, img.data[i + 1] + n));
    img.data[i + 2] = Math.max(0, Math.min(255, img.data[i + 2] + n));
  }
  ctx.putImageData(img, 0, 0);
  const tex = new THREE.CanvasTexture(canvas);
  tex.magFilter = THREE.NearestFilter;
  tex.minFilter = THREE.NearestFilter;
  tex.colorSpace = THREE.SRGBColorSpace;
  return tex;
}
```

```typescript
function makeBorderTexture(): THREE.CanvasTexture {
  const c = document.createElement('canvas');
  c.width = c.height = 64;
  const ctx = c.getContext('2d')!;
  ctx.fillStyle = 'rgba(100, 180, 255, 0.3)';
  ctx.fillRect(0, 0, 64, 64);
  ctx.strokeStyle = 'rgba(255, 255, 255, 0.8)';
  ctx.lineWidth = 4;
  for (let i = -64; i < 128; i += 16) {

    ctx.moveTo(i, 0);

    ctx.stroke();
```

## 4. 效能策略

| 項目 | 決策 |
|---|---|
| 重建節流 | `setTickInterval(0.05)` → 20 次/秒 |
| 批次模式 | 拖曳中只改資料，**放開才重建** |
| 雙層 API | `setVoxelRaw()`（只改資料）+ `markDirty()`（標記重建） |
| 估算耗時 | `rebuildMesh()` 約 2–5 ms |

### 雙層 API

```typescript
public setVoxelRaw(x: number, y: number, z: number, id: number): boolean {
  if (!this.inBounds(x, y, z)) return false;
  this.voxels[this.index(x, y, z)] = id;
  return true;   // 不標記 dirty
}

public markDirty(): void { this.dirty = true; }

public placeBlock(x: number, y: number, z: number, id: number): boolean {
  const ok = this.setVoxelRaw(x, y, z, id);
  if (ok) this.markDirty();
  return ok;
}
```

### 放置預覽規格

| 項目 | 值 |
|---|---|
| 顯示時機 | **只在上帝視角**（第一人稱不顯示） |
| 顯示內容 | 半透明方塊 |
| 材質 | **實際材質**（複製目標方塊的材質，不是純色） |
| 透明度 | **0.5**（可調） |

```typescript
// 複製目標方塊的材質，改為半透明
const previewMaterial = targetMaterial.clone();
previewMaterial.transparent = true;
previewMaterial.opacity = 0.5;
previewMaterial.depthWrite = false;   // 避免遮擋後方
```

**為什麼 `depthWrite = false`**：半透明物件若寫入深度緩衝，會導致後面的物件被錯誤遮擋。

**為什麼只在上帝視角**：第一人稱有準心直接對準目標格，預覽方塊會擋住視線。

### 線寬限制

WebGL 不支援 `linewidth > 1`，選取框線寬固定 1px。若需要更粗的視覺，改用 `Line2`（`LineMaterial`）或細長方塊。

### 套用預設設計

```typescript
/** 放置模式：目標格已有方塊時的處理方式 */
export type PlaceMode = 'replace' | 'skip';

function applyPreset(
  preset: PresetDesign,
  origin: THREE.Vector3,
  placeMode: PlaceMode = 'replace',
): void {
  for (const b of preset.blocks) {
    const x = origin.x + b.x;
    const y = origin.y + b.y;
    const z = origin.z + b.z;

    if (!this.chunk.isInBounds(x, y, z)) continue;
    if (placeMode === 'skip' && this.chunk.getVoxel(x, y, z) !== 0) continue;

    this.chunk.setVoxelRaw(x, y, z, b.blockId);
  }
  this.chunk.markDirty();
}
```

### 放置模式（`PlaceMode`）

| 模式 | 行為 | 適用情境 |
|---|---|---|
| `'replace'`（預設） | 直接覆蓋目標格 | 一般建造、套用設計 |
| `'skip'` | 目標格已有方塊就跳過，不報錯 | 疊加裝飾、不想破壞既有結構 |

**放置失敗只有一種原因**：`'outOfBounds'`（超出可建造範圍）。沒有「已被佔用」的失敗狀態 —— 佔用由 `placeMode` 決定行為。

### 預設整體旋轉

繞 Y 軸**順時針**（俯視 +Y 往下看）旋轉 90° 的倍數：

$$(x, z) \rightarrow (-z, x)$$

| 角度 | 變換 | 驗證 |
|---|---|---|
| 0° | $(x, z)$ | `(1,0,0)` → `(1,0,0)` |
| 90° | $(-z, x)$ | `(1,0,0)` → `(0,0,-1)` |
| 180° | $(-x, -z)$ | `(1,0,0)` → `(-1,0,0)` |
| 270° | $(z, -x)$ | `(1,0,0)` → `(0,0,1)` |

```typescript
function rotatePresetBlocks(
  blocks: PresetDesign['blocks'],
  degrees: 0 | 90 | 180 | 270,
): PresetDesign['blocks'] {
  const steps = (degrees / 90) % 4;
  return blocks.map(b => {
    let { x, z } = b;
    for (let i = 0; i < steps; i++) {
      const nx = -z;
      const nz = x;
      x = nx;
      z = nz;
    }
    return { ...b, x, z };
  });
}
```

### 類別分頁 UI 實作方式

**決定：自訂 HTML**（不用 `InventoryGrid`）。

`InventoryGrid`（14.8 KB）的模板寫死標題與插槽容器，**沒有分頁標籤的位置**：

```html
<div class="ui-inventory-grid">
  <div class="ui-inventory-grid-header">
    <h3 class="ui-inventory-grid-title">Inventory</h3>   ← 寫死
    <button class="ui-inventory-grid-close">&times;</button>
  </div>
  <div class="ui-inventory-grid-content" style="grid-template-columns: repeat({{columns}}, ...)">
    <div data-inventory-grid-slots></div>   ← 只有插槽容器
  </div>
</div>
```

比較：

| 路徑 | 自訂碼量 | 自訂 CSS | 依賴內部實作 | 浪費現有功能 |
|---|---|---|---|---|
| A. `InventoryGrid` + 插 DOM | ~40 行 | 只有分頁列 | 🔴 依賴 `.ui-inventory-grid-header` | ❌ 拖放用不到 |
| **B. `Card` + `mountChild(Button)`** | **~30 行** | **網格 ~15 行** | **🟢 無** | **🟢 用到 `Card` + `Button` + `mountChild`** |
| C. 完全自訂 | ~120 行 | 全部 | 🟢 無 | 🔴 浪費 `Card`、`Button`、`mountChild` |

**選 B 的理由**：

1. `Button` 的 `ghost` variant 已接近 flat design（透明背景 + hover 變色）
2. `mountChild()` 是引擎提供的組合機制（`BaseUIComponent.ts:335`），自動處理 `position: 'none'`、`initialize()`、DOM 搬移、`destroy()` 追蹤
3. 不依賴任何內部 class 名，引擎改版不會壞
4. 唯一要自己寫的是網格 CSS（~15 行）

**架構**：


- 分頁按鈕由 `PRESET_CATEGORIES` 動態生成，第一項固定是「全部」
