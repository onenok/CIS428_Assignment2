## 目標

實作音效：環境音、放置/破壞音、進度音、對話音、結束音樂。

> **已定案：整個 P8 延後到 Demo 之後。** Demo 階段完全無聲，先把玩法做通。

## 音效清單

| 音效 | 觸發 | 優先級 |
|---|---|---|
| 環境音（低頻嗡鳴） | 開場 | 中 |
| 心跳聲 | 眼睛睜開 | 低 |
| 放置方塊 | 右鍵放置 | **高** |
| 破壞方塊 | 左鍵破壞 | **高** |
| 進度 +1 | 確認設計 | **高** |
| 對話打字 | 打字機 | 低 |
| 提交音效 | Submit | 中 |
| 勝利音樂 | 勝利畫面 | 中 |

## 技術方案

| 項目 | 方案 |
|---|---|
| 音效引擎 | `ENGINE.AudioManager`（需查證 API） |
| 格式 | `.ogg`（優先）或 `.mp3` |
| 3D 音效 | 放置/破壞用 `PositionalAudio` |
| 背景音樂 | 2D 音效，`loop: true` |
