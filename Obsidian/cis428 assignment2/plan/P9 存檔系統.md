> 狀態：⏸️ 暫緩（**Demo 後再做**）

## 目標

儲存/載入玩家的建造進度。

> **已定案：整個 P9 延後到 Demo 之後。** Demo 階段是單次遊玩，不需要存檔。

## 為什麼需要

| 理由 | 說明 |
|---|---|
| 玩家可能中途離開 | 不存檔會丟失進度 |
| 測試方便 | 不用每次從頭建造 |
| 加分項 | 老師要求「better work」 |

## 技術方案

| 方案 | 說明 |
|---|---|
| **A. `localStorage`** | 最簡單，容量 ~5 MB |
| **B. IndexedDB** | 容量大，非同步 |
| **C. 檔案下載/上傳** | 玩家手動匯出 `.json` |

### 資料格式

```typescript
interface SaveData {
  version: number;
  timestamp: number;
  voxels: string;          // Base64 編碼的 Uint16Array
  progress: number;        // 0-3
  completedCategories: string[];
  playerPosition: [number, number, number];
  cameraMode: string;
}
```

### 序列化

```typescript
function serializeVoxels(voxels: Uint16Array): string {
  const bytes = new Uint8Array(voxels.buffer);
  let binary = '';
  for (let i = 0; i < bytes.length; i++) {
    binary += String.fromCharCode(bytes[i]);
  }
  return btoa(binary);
}

function deserializeVoxels(base64: string): Uint16Array {
  const binary = atob(base64);
  const bytes = new Uint8Array(binary.length);
  for (let i = 0; i < binary.length; i++) {
    bytes[i] = binary.charCodeAt(i);
  }
  return new Uint16Array(bytes.buffer);
}
```

**大小估算**：16 × 266 × 16 × 2 bytes = **136 KB** → Base64 後約 **181 KB**。`localStorage` 完全夠用。
