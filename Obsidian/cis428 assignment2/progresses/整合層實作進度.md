## 已知風險

| 風險 | 影響 | 對策 |
|---|---|---|
| 場景 JSON 手改可能被編輯器覆寫 | `gameModeClass` 失效 | **已避開**：靠 `defaultGameModeClass` fallback，不改場景 |
| `MyPlayerController` 需新增滑鼠事件 | 放置/破壞無法觸發 | **已解決**：覆寫 `handleMouseDown()` |
| UI 元件需要 `UIManager` 實例 | 無法建立 | **已解決**：用 `world.uiManager`（public readonly） |
| 25 個 chunk 首次生成可能卡頓 | Play 後短暫凍結 | 可接受；必要時分批生成 |
| `auto-imports.ts` 由編輯器產生 | 新模組可能未被註冊 | 不手改；靠編輯器掃描或顯式 import |
| headless 環境無 `document` | 測試無法跑 | **已解決**：`makeChunkTextures()` 與 `BlackOverlay.mount()` 加 headless 守衛 |
| `VoxelChunkNode` 的 mesh 是 lazy 建立 | 測試取不到 mesh | **已解決**：測試先呼叫 `rebuildMesh()` |
