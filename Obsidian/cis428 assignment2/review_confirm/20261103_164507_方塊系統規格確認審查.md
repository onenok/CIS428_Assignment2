## 原報告未涵蓋的重要問題

### 11. `VoxelShape.boxes` 可被外部修改

- **結論：** 確實存在。
- **嚴重度：** Medium。
- **證據：** 實作規格書 172-174；重構設計 160-166。
- **理由：** `readonly boxes` 只限制欄位重新指定，不限制陣列元素修改。外部可改寫 `Float64Array`，破壞 shape cache、render、raycast 與 collision 使用的幾何資料。

### 12. Neighbor update 缺少 `computeState()` 時會靜默失效

- **結論：** 確實存在。
- **嚴重度：** Medium。
- **證據：** 實作規格書 266-271、1174-1178、1224-1228。
- **理由：** `dependsOnNeighbors: true` 不保證 `computeState()` 存在；呼叫端直接略過缺少的方法，會讓依賴鄰居的方塊保留過期 state，且沒有診斷或錯誤契約。

## 修正優先順序

1. 修正 neighbor update 對 seed 方塊的重算流程。
2. 統一兩份文件的 `BlockType` API 與 phase order。
3. 決定細薄方塊的正式 collider 方案與驗收標準。
4. 補齊 Registry persistence 與 collider lifecycle 契約。
5. 修正 DDA 範例，統一 tie、normal priority 與 max-distance 規則。
6. 對 `VoxelShape` 採用 defensive copy 或 immutable representation。
7. 對 `dependsOnNeighbors` 與 `computeState()` 不一致的情況加入明確驗證或錯誤診斷。
