# N12 遊戲結束

> 狀態：🟡 待討論
> 階段：④ 結束
> 對應計劃：[[P3 結束系統]]

## 遊戲中發生什麼

遊戲結束畫面。

## 遊戲定位

> 這更像是一個**建築模擬類遊戲**，不過有一些劇情和背景設定。
> 因此「再玩一次」這種描述有點怪。

## 實作方式

| 項目 | 方案 |
|---|---|
| 結束畫面 | `CenterMessage` 或自訂 HTML |
| **統計** | **待定** —— 不確定要不要顯示 |
| **「再玩一次」** | **不用這個描述** —— 見下方替代方案 |
| **製作名單（credits）** | **要** |

## 已定案

- ✅ **要製作名單（credits）**
- ✅ **不用「再玩一次」的描述** —— 遊戲定位是建築模擬，不是關卡制

## 統計：待定

| 選項 | 說明 |
|---|---|
| A. 不顯示統計 | 純粹的結束畫面 + credits |
| B. 顯示方塊數 | 「你放置了 N 個方塊」 |
| C. 顯示建造時間 | 「花了 N 分鐘」 |
| D. 顯示截圖 | 把玩家的區塊截圖留念 |

**傾向**：可能 B 或 D 比較符合建築模擬的調性。

## 替代「再玩一次」的描述

| 選項 | 說明 |
|---|---|
| A. 「繼續建造」 | 回到建造模式，可繼續修改 |
| B. 「新的區塊」 | 開始新的空白區塊 |
| C. 「返回」 | 回到主畫面 |
| D. 不提供按鈕 | 純粹的結束畫面 |
