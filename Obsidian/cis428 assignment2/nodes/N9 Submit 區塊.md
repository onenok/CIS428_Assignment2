# N9 Submit 區塊

> 狀態：🟢 已定案
> 階段：③ 建造循環
> 對應計劃：[[P2 建造系統]]、[[P7 UI 系統]]

## 遊戲中發生什麼

玩家**隨時**可以提交自己的區塊設計。沒有硬性完成條件。

## 觸發方式

| 方式 | 說明 |
|---|---|
| **UI 按鈕** | 建造模式 UI 內的「提交」按鈕 |
| **快捷鍵** | `KeyBindings.submitDesign`（變數，預設 **`Ctrl+Enter`**） |

> 原本規劃 `Enter`，但太容易誤按（尤其對話框也用 Enter）。改為 `Ctrl+Enter`，`Alt+Enter` 可作備用。

## 流程

```
玩家按 Submit
    ↓
確認對話框「確定要提交嗎？」
    ↓
┌───────────────┬──────────────────────┐
│ 有放方塊       │ 完全空白（白卷）       │
├───────────────┼──────────────────────┤
│ → 正常結束流程 │ → 觸發彩蛋對話         │
│ → [[N10 織界者對話]] │ → 織界者：「既然你想不到，那我就自己弄了」│
│               │ → 然後進入結束流程     │
└───────────────┴──────────────────────┘
```

## 已定案

- ✅ **完全無最低要求** —— 空白區塊也能 Submit
- ✅ 先跳確認對話框（防誤按）
- ✅ UI 按鈕 + 快捷鍵都有
- ✅ **白卷彩蛋**：織界者說「既然你想不到，那我就自己弄了」
- ✅ **白卷彩蛋要有「織界者自己生成區塊」的動畫**
- ✅ **確認框按「否」可取消 Submit**

## 白卷彩蛋設計

| 項目 | 內容 |
|---|---|
| 觸發條件 | 提交時區塊內方塊數 = 0（或只有預設地形） |
| 織界者台詞 | 「既然你想不到，那我就自己弄了。」 |
| **後續動畫** | **要** —— 織界者自己生成一個區塊（方塊逐格出現） |
| 語氣 | 溫和調侃，不責備 |

### 台詞建議

```
織界者：「……」
織界者：「既然你想不到，那我就自己弄了。」
織界者：「看著吧。」
```

### 生成動畫

| 項目 | 方案 |
|---|---|
| 方式 | 方塊逐格出現（每 0.05 秒一批） |
| 順序 | 由下往上、由內往外 |
| 時長 | 約 3–5 秒 |
| 實作 | 分批 `setVoxelRaw()` + `markDirty()` |

## 實作方式

```typescript
function onSubmit(): void {
  const blockCount = chunk.getPlacedBlockCount();

  if (blockCount === 0) {
    // 白卷彩蛋
    dialogue.play(EASTER_EGG_DIALOGUE, () => {
      playLoomkeeperBuildAnimation(() => triggerEnding('blank'));
    });
  } else {
    triggerEnding('normal');
  }
}
```
