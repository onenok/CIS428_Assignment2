# N1 眼睛睜開濾鏡

> 狀態：🟡 待討論
> 階段：① 開場過場
> 對應計劃：[[P1 過場系統]]

## 遊戲中發生什麼

玩家醒來。畫面從全黑漸變為可見，模擬「睜開眼睛」。

## 實作方式

| 項目 | 方案 |
|---|---|
| 黑幕 | HTML overlay（`world.gameContainer` 內），`opacity` 1 → 0 |
| 眼睛形狀 | 上下兩片黑色遮罩，用 `clip-path` 或 `border-radius` 做眼形 |
| **眨眼效果** | **要** —— 快速開合兩次（`clip-path` 動畫序列） |
| **模糊濾鏡** | **要** —— `backdrop-filter: blur()`，隨睜眼逐漸清晰 |
| 時長 | 約 2.5 秒 |
| 玩家控制 | 全程鎖定（`setInputEnabled(false)`） |

## 已定案

- ✅ 加眨眼效果（快速開合兩次）
- ✅ 加模糊濾鏡（`backdrop-filter: blur()`）
- ⏸️ 醒來位置暫時擱置
