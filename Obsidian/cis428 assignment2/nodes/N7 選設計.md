# N7 選設計

> 狀態：🟡 待討論
> 階段：③ 建造循環
> 對應計劃：[[P2 建造系統]]

## 遊戲中發生什麼

玩家選擇一個**預設設計**作為起點，或從空白開始自由建造。

## 預設設計的定位

| 項目 | 說明 |
|---|---|
| 用途 | 讓不想從零開始的玩家方便一些 |
| 是否強制 | ❌ 可完全從空白開始 |
| 來源 | [[N6 選類別]] 的預設設計庫 |
| 內容 | placeholder，優先次序最後 |

## 實作方式

| 項目 | 方案 |
|---|---|
| 預設設計 | **placeholder**（優先次序最後，機制優先） |
| 未確認狀態 | 半透明（`opacity: 0.5`）+ 緩慢閃爍（0.4 ↔ 0.6，週期 2 秒） |
| 無碰撞 | 未確認的設計**只有顯示，沒有碰撞實體** |
| 確認後 | 變為實體，可碰撞 |
| 套用方式 | `applyPreset()` 寫入 `Uint16Array`（見 [[P2 建造系統]] §11） |
| **整體移動／旋轉** | **必須支援** —— 套用預設後可整體平移、旋轉 |
| **切換過渡效果** | **第一版不做**；Demo 後加入，可在設定中切換（預設開啟） |

## 已定案

- ✅ 預設設計用 placeholder，最後做
- ✅ 未確認 = 半透明 + 緩慢閃爍
- ✅ **無組裝動畫**（GameMaker 版才需要）
- ✅ 可完全從空白開始
- ✅ **預設設計數量無上限** —— 之後弄了多少個就有多少個
- ✅ **套用後可整體移動／旋轉**
- ✅ **切換過渡效果**：第一版不做，Demo 後加入設定開關（預設開啟）
