# N0 世界生成中

> 狀態：🟢 已定案
> 階段：⓪ 前置
> 對應計劃：[[P6 世界生成]]、[[P7 UI 系統]]

## 遊戲中發生什麼

遊戲啟動後、玩家醒來（[[N1 眼睛睜開濾鏡]]）**之前**，畫面顯示**開場影片**或**模擬遊戲開始選單**的設計。

## 已定案

- ✅ **不是進度條** —— 改為**影片**或**模擬真正遊戲開始選單**的設計
- ✅ **不做生成失敗處理**（生成必定成功）
- ✅ **不加「編織」視覺隱喻**

## 兩種呈現方式

| 方式 | 說明 | 優點 | 缺點 |
|---|---|---|---|
| **A. 開場影片** | 播放一段預錄／即時渲染的影片 | 最有質感、可講故事 | 需要製作影片素材 |
| **B. 模擬遊戲開始選單** | 仿遊戲主選單（Continue / New Game / Settings） | 有遊戲感、可互動 | 需要額外 UI |

> **待決定**：A 還是 B（或兩者結合：選單 → 按 Start → 影片 → 進遊戲）

## 為什麼放在 N1 之前

| 理由 | 說明 |
|---|---|
| 技術現實 | 世界生成需要時間（方塊資料、網格建構） |
| 敘事合理 | 世界「還沒織完」，正好呼應織界者的設定 |
| 避免黑屏 | 有內容比純黑幕好 |

## 實作方式

| 項目 | 方案 |
|---|---|
| UI | 全螢幕 overlay（`world.gameContainer` 內） |
| 影片 | HTML `<video>` 或 `VideoTexture` |
| 選單 | `Button` + `Card` 組合 |
| 時長 | 依實際生成時間（目標 < 3 秒） |

## 流程

```
遊戲啟動
    ↓
[N0] 開場影片 / 模擬開始選單
    ↓
[N1] 眼睛睜開濾鏡
    ↓
[N2] 環境描述對話
```
