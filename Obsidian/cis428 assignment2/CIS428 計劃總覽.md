## 怎麼用這個看板

### 1. 看遊戲流程

Canvas 上半部是**遊戲流程**，分五個階段：

| 階段 | 節點 | 顏色 |
|---|---|---|
| ⓪ 前置 | N0 | 灰 |
| ① 開場過場 | N1 → N2 → N3 | 紫 |
| ② 自由探索 | N4 → N5 | 青 |
| ③ 建造循環 | N6 → N7 → N8 → N9（循環） | 綠 |
| ④ 結束 | N10 → N12（N11 暫緩） | 紅 |

### 2. 看實作方式

Canvas 下半部是**計劃層**（P1–P10），虛線連到對應的遊戲節點。

**一個 P 節點可以連到多個 N 節點** —— 例如 `P2 建造系統` 對應 N4–N9。

### 3. 修改計劃

**雙擊任何節點** → 開啟對應的 `.md` 檔案 → 直接編輯。

編輯後 Canvas 會自動更新節點預覽。

### 4. 告訴我要改什麼

在 `.md` 檔案裡加標記，或直接在對話中說：

| 你想做的事 | 怎麼說 |
|---|---|
| 擴充某節點 | 「擴充 P2」或「P2 要加 X」 |
| 補漏 | 「N5 和 N6 之間漏了 X」 |
| 改設計 | 「N7 的閃爍改成 X」 |
| 問問題 | 「N8 的批次模式怎麼運作？」 |

## 狀態標記

每個 `.md` 檔案開頭有狀態：

| 標記 | 含義 |
|---|---|
| 🟢 已定案 | 規格確定，可直接實作 |
| 🟡 待討論 | 有基本方向，細節未定 |
