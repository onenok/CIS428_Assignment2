## 審查 → 修正的流程

```
外部審查結論
    ↓
逐項查證（不盲信，也不盲疑）
    ↓
分類：屬實 / 部分屬實 / 不成立
    ↓
補上審查漏掉的問題
    ↓
排優先次序（不修就玩不了 → 不修只是不完整）
    ↓
修正 → 更新進度表
```
