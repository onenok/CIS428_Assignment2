## 二、新發現與未解決問題

### 1. 子格細分會縮小完整方塊碰撞體 — Critical

實作規格中的 `voxelSize = 1 / SUBDIVISION`，但完整方塊只加入單一 `(x, y, z)` 子格座標。當 `SUBDIVISION = 2` 時，完整方塊只覆蓋半格，會造成碰撞體縮小並錯位。

**修正：** 完整方塊必須展開所有子格，或明確使用另一套完整方塊座標系統，並加入 world bounds 測試。

### 2. `shapeContains(center)` 會讓細薄碰撞形狀消失 — High

只測試子格中心點是否在 shape 內，會使厚度小於半格的柵欄、火把等形狀沒有任何碰撞子格。

**修正：** 改用子格與 shape 的相交測試，或明確限制 shape 必須對齊子格並驗證最小厚度。

### 3. DDA 缺少零方向與輸入驗證 — High

規格未定義 `dir = (0,0,0)` 或無限 `maxDistance` 的行為，可能造成 `tMax = Infinity` 且迴圈永不結束。

**修正：** 入口驗證 direction 必須為 finite 且長度大於 epsilon，`maxDistance` 必須為 finite 且非負；無效輸入應明確拋錯或回傳 `null`。

### 4. DDA tie handling 仍可能漏格 — High

使用精確 `tMaxX === next` 比較，沒有浮點容差，也沒有定義 edge/corner 的 supercover 或優先軸語意。

**修正：** 定義 tie epsilon、traversal policy、tie 時法向量規則，並加入單軸、雙軸、三軸 tie 測試。

### 5. Neighbor worklist 的 `visited` 可能阻止必要重算 — High

每個 cell 只允許處理一次，但後續鄰居變化可能使同一 cell 需要重新計算。這會使樓梯、柵欄或多格 batch 編輯無法達到 fixed point。

**修正：** 使用 `queued/inQueue` 管理排程；state 實際變更時重新加入 queue；加入最大迭代數並在未收斂時明確報錯。

### 6. Registry ID 不是穩定持久化 identity — High

ID 依註冊順序分配。新增、刪除或重新排序註冊項目後，同一 ID 可能代表不同 block state。

**修正：** 定義 registry version、`namespace:type + canonical properties` 持久化 key、runtime ID mapping、unknown block fallback、palette serialization 與舊版本 migration。

### 7. Undo/redo 尚未定義 neighbor 與 rebuild 語意 — High

規格只說 undo 改用 `setVoxel()`，但未定義是否重新執行 neighbor update、是否以單一 transaction 執行、如何收集 dirty chunks，以及 redo stack 的清理時機。

**修正：** 把 undo/redo 定義為完整 world mutation transaction，回放後重新執行 neighbor fixed-point、dirty chunk 收集、mesh/collider rebuild。

### 8. Multi-box meshing 的內部面與面積覆蓋未規格化 — Medium

`coversFace()` 只能處理單一 box 完整覆蓋，無法處理多 box 合併覆蓋；同一 shape 內部面及跨 block 的部分面遮蔽也未明確定義。cross geometry 仍是 AABB 近似。

**修正：** 定義內部面剔除、面積 union、render type（cube/cross/model）與 mesh builder API，並標示哪些是暫時近似。

### 9. 兩份文件對 collider remove/rebuild 契約矛盾 — Medium

重構設計與實作規格對 `removeNode()` 是否會從 `bodies` map 移除有相反描述，直接影響 collider 更新 workaround 是否有效。

**修正：** 保留唯一的引擎驗證結果，並用實際編輯後 collider 更新測試取代單純 API 假設。

### 10. Palette accessor 對無效 index 靜默回傳 air — Medium

`stateIds[index] ?? 0` 會把越界或損壞資料靜默轉成 air，掩蓋 raw access migration 與序列化錯誤。

**修正：** `stateAt()` 對無效 index 拋錯；只有明確的 corrupted-data recovery 路徑才允許回退 air。

## 三、目前已充分定義的部分

- Voxel-local 與 world 座標轉換的基本方向
- `VoxelRaycastWorld` 跨 chunk 存取介面
- 未載入 chunk 終止射線
- `placementCell = hit.cell + hit.normal`
- `breakCell = hit.cell`
- Palette index 與 global state ID 的基本分離
- 主要 raw access 遷移清單
- `Float64Array` shape 格式與基本驗證
- 不再使用不可行的 voxel-plus-cuboid compound 方案
- worklist 取代遞迴的方向
- render/collision/outline 三層分離概念
