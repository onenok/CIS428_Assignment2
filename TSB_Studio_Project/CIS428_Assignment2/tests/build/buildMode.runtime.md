# 執行期驗證清單 — 建造系統

> **層級**：第 3 層（MCP 執行期）
> **對象**：建造模式（放置／破壞／選取框／雙視角）
> **前置**：`pnpm verify` 全綠、`pnpm build` 成功

第 3 層無法自動化 —— 它驗證的是「看起來對不對」「手感好不好」。每一項都要在
TSB Studio 的 play mode 中親眼確認，並用 `captureScreenshot` 留下證據。

---

## 執行方式

1. 在 TSB Studio 開啟專案
2. `query_editor(getState)` 確認 `editorReady: true`
3. `action_editor(enterPlayMode)`
4. 逐項操作，每項通過後打勾
5. 失敗項目開一個 `ISSUE-XXX`，分類 `blocker` 或 `polish`
6. `action_editor(exitPlayMode)`

## 失敗處理

| 嚴重度 | 定義 | 動作 |
|---|---|---|
| `blocker` | 功能完全不能用 | 立刻修，不繼續下一組 |
| `content` | 功能可用但內容錯 | 開 issue，用 placeholder 繼續 |
| `polish` | 可用但不好看／不順 | 開 issue，Demo 後處理 |

開 issue 時附上：檢查項編號、實際行為、預期行為、截圖。
